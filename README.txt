# Internship Task 1 – Basics of Web Development

## Project
My Personal Webpage

## Files
- `index.html` – webpage structure, headings, paragraphs, image and links.
- `style.css` – colours, fonts, spacing, cards, layout and mobile responsiveness.
- `script.js` – button click alert and automatic footer year.

## How to run
1. Extract the ZIP file.
2. Open the `task1_web_development` folder.
3. Double-click `index.html`, or open it in a browser.
4. Click the **Click Me** button to test the JavaScript alert.
5. Resize the browser or open it on a phone to test the responsive CSS.

## Requirements completed
1. HTML: headings, paragraphs, image, navigation links and sections.
2. CSS: colours, typography, spacing, hover effects, cards and responsive layout.
3. JavaScript: button click event displays an alert message.

Note: The sample workspace photo is loaded from Unsplash, so an internet connection is needed to display it. The rest of the webpage works locally.
