# Task 2 – Intermediate HTML, CSS and JavaScript

## Project features
1. Contact form built with HTML and styled using CSS.
2. JavaScript form validation for required fields and email format.
3. Responsive page layout using Flexbox, CSS Grid and media queries.
4. Dynamic to-do list: add tasks, mark tasks complete, delete tasks and clear completed tasks.
5. Responsive mobile navigation.

## Files
- `index.html` – page structure and form/list elements.
- `style.css` – colors, layout, styling and responsive rules.
- `script.js` – form validation, navigation and to-do list behavior.

## How to run on Windows
1. Download and extract this ZIP file.
2. Open the extracted `Task_2_Intermediate_HTML_CSS_JavaScript` folder.
3. Open the folder in Visual Studio Code.
4. Open `index.html`.
5. Right-click inside the file and choose **Open with Live Server** (if the Live Server extension is installed).
   - Or double-click `index.html` to open it directly in your browser.

## How to test
- Submit the contact form empty: required-field messages should appear.
- Enter an invalid email: an email-format error should appear.
- Enter valid details: a success message should appear. This is a front-end demo; it does not send email.
- Add a task, tick it as completed, delete it, and use **Clear completed**.
- Resize the browser or open the page on a phone to test responsive layout.

## Technologies
HTML5, CSS3 and JavaScript (Vanilla JS).

## Note
The contact form is a front-end demonstration only. To deliver messages to an inbox, a server-side endpoint or form service must be connected.
